# Architecture

## Principles

- **Offline-first:** Core map, layers, and Land Info work without network after install/download.
- **Zero-infra:** No backend, no auth, no cloud sync. Static files only.

## Supported clients

| Platform | Status | Notes |
|----------|--------|--------|
| **Android** | Shipped | MapLibre Native + offline packs; also BlueStacks / Android emulators on a desktop |
| **iOS** | Code target, not shipped | Must stay buildable in principle, but never compiled and nothing published — free signing expires in 7 days and needs network to renew. See [ios.md](ios.md) |
| Windows / macOS / Linux (native) | Out of scope | MapLibre Flutter has no desktop engine — use an Android emulator instead |
| Web | Out of scope | Not a product target |

**Stack:** Flutter + MapLibre · GeoJSON / optional PMTiles · local storage

- Default basemap: **Streets** via OpenFreeMap (needs network).
- **Satellite**: provincial orthophotography over Sentinel-2 cloudless (needs network).
- **Hybrid**: satellite with OpenFreeMap's roads, watercourses, boundaries and
  place names over it, generated by `tools/gis/build_hybrid_style.py`.
- **Offline**: bundled blank style plus the pack's overlays (no street/satellite tiles).
- Province packs under `data/{cc}/` → GitHub Releases ZIPs; Download/Import on mobile.
- Basemap areas: MapLibre's own offline regions, sized up beforehand by
  `app/lib/offline/tile_math.dart`. See [Offline packs](packs.md).

## Data delivery

| Channel | Use |
|---------|-----|
| App bundle | `provinces.json` catalogue and map styles only |
| GitHub Releases | Province overlay packs (`on-overlays.zip`, …) |

Province packs are static ZIPs (`manifest.json`, `overlays/`, optional `policies/` and `seasons/`). On Android/iOS, Download or Import extracts to `offline_packs/{province}/`. No province data is bundled, so a province with no pack shows a download prompt instead of a map.

### Overlays are rendered from disk

The app hands MapLibre a `file://` path per layer and never parses overlay geometry itself. Decoding a layer in Dart and passing it over the platform channel copies every feature onto the Android heap as well — for Ontario's 42.7k Crown parcels that overruns the per-app heap cap and kills the process. Layer-wide facts (tenure, accuracy, basis notes) come from the `metadata` object at the head of each file, read without touching the geometry behind it.

## My maps (user-supplied imagery)

Two kinds, one code path. A Garmin Custom Map KMZ is unzipped once into
`custom_maps/{id}/`; each of its `GroundOverlay` images becomes a MapLibre
`image` source, four corner coordinates and a bitmap. An XYZ tile URL becomes a
`raster` source. Both are drawn by a raster layer, which is what lets one
opacity slider serve both.

An imported file is a grid, so only the images near the view are held: overlays
are culled on camera idle and capped at `maxDrawnOverlays`, because each one
decodes a JPEG on the platform side and a full 1:20,000 sheet is more bitmaps
than a phone will hold at once. Idle rather than every camera move, for the same
reason.

Layer order is stated rather than inherited. Every custom layer names the drawn
neighbour it belongs under, added from the top of the stack down, so two maps
over the same ground stack the way the list reads instead of however MapLibre
happens to break a tie between layers inserted below one anchor. The whole band
sits below the lowest `owm-` layer.

A tile URL that resolves but serves nothing draws an empty layer and cannot be
told from a bug, so `checkTileUrl` refuses what a bad paste actually looks like
— whitespace inside the URL, two addresses glued together, WMS parameters, `{s}`
server rotation — by name, at the dialog, while the cause is still on screen.

## Waypoints

- Stored **locally only** (device storage). Never uploaded or synced.
- GPS track recording on mobile.

## Land Info (identify)

1. User taps map.
2. `queryRenderedFeatures` asks MapLibre what is under the tap, one layer at a time so each hit keeps its layer.
3. Report shows **local government** (bylaws) + land-use / policy notes, plus a Seasons tab keyed to the WMU.
4. Policy docs from the pack under `policies/`.

WMU and municipality are always hit-testable because Land Info needs them for seasons and by-laws; switching their outlines off drops them to zero opacity rather than hiding them, since MapLibre only queries layers it still renders.

## Layer pipeline (out of band)

Source GIS → normalize → GeoJSON → `tools/gis/build_pack.py` → GitHub Releases.
